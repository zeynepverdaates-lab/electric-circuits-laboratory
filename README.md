## 📚 Laboratory Experiments

### Experiment 1: Fundamentals of AVO Meter (Multimeter) Measurements
- **Objective:** Understanding the operational principles of analog and digital multimeters; measuring DC voltage, current, and equivalent resistance; analyzing internal meter resistances and loading effects.
- **Key Concepts Covered:**
  - Resistor color code decoding and tolerance evaluation
  - Internal resistance effects in voltage ($R_v \to \infty$) and current ($R_a \to 0$) measurements
  - Loading effect and percentage error calculations:
    $$\% \text{Error} = \frac{\vert{}\text{Theoretical} - \text{Experimental}\vert{}}{\text{Theoretical}} \times 100$$
- **Documentation:** [📄 View AVO Meter Lab Report (PDF)](Lab01_AVO_Meter/AVO_Meter_Report.pdf)
